# CHISPA: El mundo se apaga

Prototipo Godot 4.4.1 para Android de plataformas + puzles de luz y oscuridad. Conserva el personaje azul original, pasto, tachos y gaviota.

## Jugar

- **Móvil horizontal**: flechas de izquierda/derecha; SALTO; LUZ.
- **PC**: A/D o flechas, Espacio o W para saltar (doble salto permitido), E para cambiar la fase luminosa, R para reiniciar.
- Las plataformas **celestes** solo son sólidas con la luz encendida; las **violetas**, con la luz apagada. Las verdes siempre son sólidas.
- Llegá a la puerta brillante para superar cada uno de los **3 niveles prototipo**.

## Instalar

Subí **el contenido de esta carpeta a la raíz del repositorio** (project.godot en la raíz). El workflow `.github/workflows/android.yml` compila el APK en Actions; buscá el artefacto `Chispa-Android-APK`. Android APK de **depuración**, no apto para publicar en Google Play. No fue validado en un dispositivo real.

> Se mantienen los cuatro recursos originales. Este prototipo tiene 3 niveles y no los 100 niveles potenciales de la idea original.
